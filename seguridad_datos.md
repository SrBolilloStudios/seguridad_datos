# Conceptos Básicos de Seguridad de la Información

## 1. Tríada CIA (CID)

Es el modelo fundamental para establecer políticas de protección de
datos.

-   **Confidencialidad:** Asegura que la información solo sea accesible
    para personas o sistemas autorizados.
-   **Integridad:** Garantiza que los datos se mantengan precisos,
    completos y sin modificaciones no autorizadas.
-   **Disponibilidad:** Asegura que los sistemas y la información estén
    accesibles cuando los usuarios autorizados los necesiten.

------------------------------------------------------------------------

## 2. Gestión de Riesgos

La seguridad se analiza a través de la interacción de estos elementos
clave:

-   **Activo:** El recurso que se desea proteger (datos, hardware,
    reputación).
-   **Vulnerabilidad:** Una debilidad o fallo interno en el diseño o
    implementación de un sistema.
-   **Amenaza:** Cualquier evento potencial (externo o interno) que
    puede explotar una vulnerabilidad para causar daño.
-   **Impacto:** La magnitud del daño o pérdida si la amenaza se
    materializa.
-   **Riesgo:** La probabilidad de que una amenaza aproveche una
    vulnerabilidad. Se calcula comúnmente como:

`Riesgo = Probabilidad × Impacto`

------------------------------------------------------------------------

## 3. Triángulo de Seguridad, Usabilidad y Funcionalidad

Este modelo describe la tensión inherente en el diseño de sistemas;
aumentar un factor suele degradar los otros dos:

-   **Seguridad:** Restricciones y controles aplicados.
-   **Usabilidad:** Facilidad de uso y experiencia del usuario.
-   **Funcionalidad:** Características y capacidades operativas del
    sistema.

------------------------------------------------------------------------

## 4. Autenticación Multifactor (MFA)

Método que requiere al menos dos factores de categorías distintas para
verificar una identidad:

-   **Algo que sabes (Conocimiento):** Contraseñas, PIN o preguntas de
    seguridad.
-   **Algo que tienes (Posesión):** Tokens físicos, tarjetas
    inteligentes o el teléfono móvil.
-   **Algo que eres (Inherencia):** Datos biométricos como huellas
    dactilares o reconocimiento facial.
